# Quick Setup - Lines 2-3 of .env.local

## What Line 2-3 Currently Has:

```env
DATABASE_URL=postgresql://user:password@host:port/database
```

## What You Need To Do:

**Replace line 2 with your actual PostgreSQL connection string.**

---

## Option 1: Use Neon (Easiest - 2 minutes)

### Step 1: Get Connection String
1. Go to https://neon.tech
2. Sign up (free, use GitHub)
3. Click "Create Project"
4. After project is created, you'll see a connection string like:
   ```
   postgresql://username:password@ep-xxx-xxx.us-east-2.aws.neon.tech/neondb
   ```
5. **Copy this entire string**

### Step 2: Update Line 2
Replace line 2 in `.env.local` with:
```env
DATABASE_URL=postgresql://username:password@ep-xxx-xxx.us-east-2.aws.neon.tech/neondb?sslmode=require
```

**Important:** Add `?sslmode=require` at the end for SSL.

### Step 3: Run Database Schema
1. In Neon dashboard → Click "SQL Editor"
2. Click "New Query"
3. Open `lib/db-schema.sql` from your project
4. Copy ALL the SQL code
5. Paste into Neon SQL Editor
6. Click "Run" button

### Step 4: Done!
Your line 2 should now look like:
```env
DATABASE_URL=postgresql://neondb_owner:AbC123XyZ@ep-cool-name-123456.us-east-2.aws.neon.tech/neondb?sslmode=require
```

## Option 2: Use Supabase

### Step 1: Get Connection String
1. Go to https://supabase.com
2. Sign up → Create new project
3. Go to **Settings** → **Database**
4. Scroll to "Connection string" → Select "URI" tab
5. Copy the connection string
6. Replace `[YOUR-PASSWORD]` with your actual database password

### Step 2: Update Line 2
```env
DATABASE_URL=postgresql://postgres:your_password@db.xxx.supabase.co:5432/postgres?sslmode=require
```

### Step 3: Run Schema
1. Go to **SQL Editor** in Supabase
2. Copy `lib/db-schema.sql` content
3. Paste and run

---

## Option 3: Use Railway

### Step 1: Get Connection String
1. Go to https://railway.app
2. Sign up with GitHub
3. New Project → Add PostgreSQL
4. Click PostgreSQL service → Variables tab
5. Copy `DATABASE_URL` value

### Step 2: Update Line 2
```env
DATABASE_URL=postgresql://postgres:password@containers-us-west-xxx.railway.app:5432/railway
```

### Step 3: Run Schema
1. Click PostgreSQL → Data tab → Query
2. Copy `lib/db-schema.sql` content
3. Paste and run

**Replace `your_actual_connection_string_here` with your real connection string!**
