# How to Get Your MongoDB Connection String (MONGODB_URI)

## 🎯 Quick Steps (5 minutes)

### Step 1: Create MongoDB Atlas Account
1. Go to **https://www.mongodb.com/cloud/atlas**
2. Click **"Try Free"** or **"Sign Up"**
3. Sign up with:
   - Google (easiest)
   - GitHub
   - Or email

### Step 2: Create a Free Cluster
1. After signup, click **"Build a Database"**
2. Select **FREE** tier (M0 Sandbox) - It's free forever!
3. Choose a cloud provider:
   - **AWS** (recommended)
   - Google Cloud
   - Azure
4. Select a region closest to you
5. Click **"Create Cluster"**
6. Wait 1-3 minutes for cluster to be created

### Step 3: Create Database User
1. In the setup wizard, you'll be asked to create a database user:
   - **Username**: `cesquiz` (or any username you want)
   - **Password**: Click "Autogenerate Secure Password" or create your own
   - **IMPORTANT**: Save this password! You'll need it!
   - Click **"Create Database User"**

### Step 4: Set Network Access
1. Click **"Add My Current IP Address"** (for development)
2. Or click **"Allow Access from Anywhere"** (for deployment)
   - For production, use specific IPs for security
3. Click **"Finish and Close"**

### Step 5: Get Your Connection String
1. Once your cluster is ready, click the **"Connect"** button
2. Choose **"Connect your application"**
3. Select:
   - **Driver**: Node.js
   - **Version**: 5.5 or later
4. You'll see a connection string like this:
   ```
   mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority
   ```
5. **Copy this entire string**

### Step 6: Update Your Connection String
Replace the placeholders in your copied string:

**Before:**
```
mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority
```

**After (replace these):**
- `<username>` → Your database username (e.g., `cesquiz`)
- `<password>` → Your database password (the one you saved!)
- Add database name: Add `/ces_quiz` before the `?`

**Final format:**
```
mongodb+srv://cesquiz:your_password_here@cluster0.xxxxx.mongodb.net/ces_quiz?retryWrites=true&w=majority
```

### Step 7: Add to .env.local
Open your `.env.local` file and update:

```env
MONGODB_URI=mongodb+srv://cesquiz:your_password_here@cluster0.xxxxx.mongodb.net/ces_quiz?retryWrites=true&w=majority
SESSION_SECRET=Ay5Suwm4kH+YoM2Dhh+drualnX7K19/fMMF1/oQWvOA=
```

**Important:** 
- Replace `your_password_here` with your actual password
- Replace `cluster0.xxxxx.mongodb.net` with your actual cluster address
- Keep the `/ces_quiz` database name
- Keep the `?retryWrites=true&w=majority` parameters

## 🔍 Example Connection String Breakdown

```
mongodb+srv://cesquiz:MyPassword123@cluster0.abc123.mongodb.net/ces_quiz?retryWrites=true&w=majority
│         │      │          │              │                    │         │
│         │      │          │              │                    │         └─ Query parameters
│         │      │          │              │                    └─ Database name
│         │      │          │              └─ Cluster address
│         │      │          └─ Password
│         │      └─ Username
│         └─ Protocol (mongodb+srv for Atlas)
└─ MongoDB connection string
```

## ✅ Verify Your Connection String

Your connection string should:
- ✅ Start with `mongodb+srv://`
- ✅ Include your username and password
- ✅ Have your cluster address
- ✅ Include `/ces_quiz` (database name)
- ✅ End with `?retryWrites=true&w=majority`

---

## 🚨 Common Issues

### Issue: "Authentication failed"
**Solution:** 
- Check username and password are correct
- Make sure you replaced `<username>` and `<password>` in the string
- Verify password doesn't have special characters that need URL encoding

### Issue: "Connection timeout"
**Solution:**
- Check your IP is whitelisted in Network Access
- Try "Allow Access from Anywhere" temporarily
- Verify connection string format

### Issue: "Invalid connection string"
**Solution:**
- Make sure you added `/ces_quiz` before the `?`
- Check for extra spaces or line breaks
- Verify all parts of the string are present

## 🧪 Test Your Connection

After updating `.env.local`:

1. Restart your dev server:
   ```bash
   npm run dev
   ```

2. Check console for:
   - ✅ `Connected to MongoDB` = Success!
   - ❌ `MongoDB connection error` = Check your connection string

3. Try registering a user at http://localhost:3000
   - If it works → Connection is good! ✅
   - If error → Check connection string format
